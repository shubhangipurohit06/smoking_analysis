# 🚬 Smoking Analysis — Data Analytics Project

## 📌 Project Overview

**Smoking Analysis** is a data analytics project focused on exploring patterns and relationships between smoking behavior and different demographic, lifestyle, and health-related factors.

The objective of this project is to perform **data cleaning, exploratory data analysis (EDA), statistical analysis, and visualization** to identify meaningful patterns in the dataset and generate data-driven insights.

---

## 🎯 Business Objective

The project aims to answer questions such as:

* What percentage of people in the dataset are smokers?
* How does smoking behavior vary across different age groups?
* Is there a relationship between smoking and gender?
* How does smoking status differ across different demographic groups?
* Are smokers more likely to have certain health or lifestyle characteristics?
* Which factors appear to be associated with smoking behavior?
* What insights can be derived to support awareness and preventive-health initiatives?

## 📊 Exploratory Data Analysis

The analysis focuses on understanding the distribution of smoking behavior and its relationship with other variables.

### Key areas explored

**Demographic Analysis**

* Age distribution
* Gender distribution
* Smoking status across demographic groups

**Lifestyle Analysis**

* Relationship between smoking and lifestyle-related variables
* Comparison of smokers and non-smokers

**Health Analysis**

* Comparison of health-related characteristics between smoking groups
* Identification of potential patterns and associations

## 🔍 Key Insights

The analysis was used to identify patterns such as:

* Distribution of smokers and non-smokers within the dataset
* Differences in smoking behavior across demographic groups
* Relationships between smoking and lifestyle factors
* Differences in selected health-related variables between groups
* Variables that may have an association with smoking behavior

> **Note:** These observations represent patterns within the analyzed dataset and should not automatically be interpreted as causal relationships.

## 💡 Business Recommendations

Based on the analysis, organizations working in public health, awareness, or preventive programs could:

1. Identify demographic groups with comparatively higher smoking prevalence.
2. Use data-driven segmentation for targeted awareness campaigns.
3. Focus preventive initiatives on groups showing higher-risk patterns.
4. Monitor lifestyle factors associated with smoking behavior.
5. Use periodic data analysis to evaluate changes in smoking patterns.
